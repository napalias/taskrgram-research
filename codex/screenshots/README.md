## Privacy note

Some authenticated screenshots contain account-specific data visible in the authorized session, including the phone number and recent Telegram service messages. Keep this folder private. QR-code login screenshots were intentionally not retained because a QR code can encode a temporary authentication token.

Supporting observations and DOM evidence are recorded in [../evidence.md](../evidence.md).
